# volcanolabel WeChat article kit

This folder contains the user-facing article draft and image assets for a
WeChat public account post.

- `volcanolabel-user-guide.html`: standalone article draft.
- `generate_wechat_assets.R`: regenerates all figures from the current package.
- `assets/`: cover images, article figures, and `IMAGE_MANIFEST.tsv`.

Recommended WeChat dimensions used here:

- Main cover: `900 x 383` px, plus `1800 x 766` retina export.
- Share card: `500 x 400` px.
- Square secondary cover: `1080 x 1080` px.
- In-article figures: `1080` px wide PNGs.
